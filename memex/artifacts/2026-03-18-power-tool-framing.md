# Power Tool Framing

The Memex is a power tool for intellectual research and review. It does not degrade gracefully for disengaged operators — if the PI stops investigating, the system silently rots. This is the same property that makes it valuable: deep engagement is rewarded with continuity no other tool provides.

**Audience**: people engaged in sustained intellectual work who use LLMs as research infrastructure. Not everyone. The system self-selects.

**Vulnerability**: the architecture's strength (everything connected, lifecycle-managed, adversarially audited) becomes its failure mode under neglect. Wikis and message boards survive neglect because they're simpler. The Memex demands more and returns more.

**Open question**: as the repo ages and accumulates real operational history, does the power-tool framing need to be made explicit in the README? Current instinct: not yet. Let the proof build first.

**Origin**: emerged from a session combining ChatGPT's hostile review with internal self-criticism. The hostile reviewer identified the gaps; the PI identified the audience.
